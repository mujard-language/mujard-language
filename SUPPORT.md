# Support

## Security issues

**Do not report vulnerabilities in public issues.** See `SECURITY.md` for the
private reporting channel and safe-harbor terms. For the open-source components
(language, compiler, runtime, CLI, toolchain) the process is
`docs/governance/open-source/OSS-SEC-008`; platform security reports go through
the platform's own channel.

## Bugs and feature requests

- Open components (compiler, CLI, language, docs): the issue tracker on this
  repository (github.com/mujard-language/mujard-language).
- Platform issues (apps, accounts, billing, hosted services): use the in-app
  feedback/support channel.

## Questions

- Language usage: `docs/lang/README.md` (built-ins reference) and
  `docs/lang/MUJARD_LANGUAGE_SPEC.md` (the specification).
- Contributing: `CONTRIBUTING.md` and `docs/governance/open-source/OSS-CON-003`.
- Governance and decision-making: `docs/governance/open-source/OSS-GOV-001`.
